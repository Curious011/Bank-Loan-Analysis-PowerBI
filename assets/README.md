# Dashboard Screenshots Guide

Save your Power BI screenshots in this folder using the following filenames:

1. **`summary_view.png`** - Full-screen screenshot of the **Summary** page (KPI cards, Good vs. Bad loans, Loan status table).
2. **`overview_view.png`** - Full-screen screenshot of the **Overview** page (Monthly trends, Purpose, Term, Employment, Home Ownership, State slicer).

### How to take clean screenshots:
1. Open `Bank_Loan_Analysis_Report.pbix` in Power BI Desktop.
2. Go to **View** > **Full screen**.
3. Press **`Win + Shift + S`** (Windows Snipping Tool) or **`Print Screen`**.
4. Save the images into this `assets/` folder with the names `summary_view.png` and `overview_view.png`.
5. Once saved, they will automatically render inside the root `README.md`.
